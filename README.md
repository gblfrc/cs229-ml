# CS229 - Machine Learning

This folder contains my personal attempts to the Fall 2018 Problem Sets of the *CS229 - Machine Learning*  course from Stanford University. These solutions were never officially graded by the university, as I was never officially enrolled to the course and followed it only for personal interest in Spring 2026.

### Material availability

A clean version of the assignments, along with the official solutions, can be downloaded from [this repository](https://github.com/maxim5/cs229-2018-autumn).

The syllabus with the topics addressed during the course is available from the [official course website](https://cs229.stanford.edu/syllabus-autumn2018.html). For studying, the syllabus and notes for the [Fall 2022 edition](https://cs229.stanford.edu/syllabus-fall2022.html) were followed.

Lectures from Fall 2018 were recorded and made available [here](https://www.youtube.com/playlist?list=PLoROMvodv4rMiGQp3WXShtMGgzqpfVfbU).
